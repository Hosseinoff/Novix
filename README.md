# NOVIX — Hossein Tavakoli

Responsive personal portfolio built with HTML, CSS and JavaScript.

## Included
- RTL Persian UI
- iOS-inspired glassmorphism
- Responsive breakpoints for desktop/tablet/mobile
- Functional mobile navigation
- Smooth anchor navigation
- Accessible keyboard focus and skip link
- Reveal animations with reduced-motion support
- SEO metadata, Open Graph, robots.txt and sitemap.xml
- LUMA / DIBA / LAVA / NAVA project links
- Contact and social links

## Deploy
Upload the entire `Novix` folder to GitHub Pages and keep the folder structure unchanged.
